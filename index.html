차고지 설치 확인 구비서류 유형별 정리

이용하시는 주차장 유형에 따라 구비서류가 상이합니다.

  • 노외주차장 이용 시: 차고지신청서 + 월세계약서 + 주차장 사업자등록증
  • 타인 소유 나대지 이용 시: 차고지신청서 + 토지사용승낙서 + 토지주 인감증명서 + 토지대장
  • 본인 소유 나대지 이용 시: 차고지신청서 + 토지대장 + 신분증
  • 아파트 주차장 이용 시: 차고지신청서 + 아파트경비실 직인 승낙서 + 주차위치 지도/사진
  • 연립·빌라 거주 시: 차고지신청서 + 주민 100% 동의 승낙서 + 등본 + 건축물대장 + 주차사진
해당 차량이 1.5톤 초과인 경우 차고지 설치 확인서가 필수로 요구됩니다.
